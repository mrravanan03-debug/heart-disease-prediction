## 🧠 About The Project

**CardioPredict AI** is a machine learning-based heart disease prediction project developed to explore how artificial intelligence can be applied to healthcare data.

The system analyzes relevant patient health attributes and uses a trained machine learning model to predict whether a person may be at risk of heart disease.

> ⚠️ **Disclaimer:** This project is intended for educational and research purposes only. It is not a medical diagnostic tool and should not replace professional medical advice.
